🧠 Online Quiz & Result System

📌 Project Overview

The Online Quiz & Result System is a simple web-based quiz application developed using HTML, CSS, and JavaScript.

It allows users to answer multiple-choice questions, complete the quiz within a given time, and view their final score instantly.

This project is developed as Web Technology Project 9.

---

Live Website Link 
https://jananijoy15.github.io/Online-Quiz-Result-System/

✨ Features

- 📝 Multiple-choice quiz questions
- ⏱️ 5-minute countdown timer
- ✅ Automatic answer checking
- 🏆 Instant score calculation
- 💬 Performance-based result message
- 🔄 Try Again option
- 📱 Mobile responsive design
- 🖤 Black and Purple professional UI
- ⚡ No database or backend required

---

🛠️ Technologies Used

- HTML5 – Structure of the web page
- CSS3 – Styling and responsive design
- JavaScript – Quiz logic, timer and score calculation

⚙️ How It Works

1. Open the quiz application.
2. The 5-minute timer starts automatically.
3. Select one answer for each question.
4. Click Submit Quiz.
5. JavaScript checks the selected answers.
6. The final score is calculated automatically.
7. A performance message is displayed.
8. Click Try Again to restart the quiz.

⏱️ Timer Function

The application uses JavaScript to create a 5-minute countdown timer.

If the timer reaches zero, the quiz is automatically submitted and the result is displayed.

📊 Result System

The result is calculated based on the number of correct answers.

Score| Message
5/5| Excellent! Perfect score!
3–4/5| Good job! Keep improving!
0–2/5| Keep practicing and try again!
